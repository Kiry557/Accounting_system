# Accounting System

A web application for managing accounting data and financial operations.

## Features

- Manage accounting and financial data.
- View and organize financial information through a user-friendly interface.

## Tech Stack

- **Frontend:** NiceGUI
- **Backend:** Python
- **Database:** PostgreSQL

## Project Structure

```text
Accounting_system/
├── main.py
├── requirements.txt
├── README.md
└── ...
```

- `main.py` — Application entry point.
- `requirements.txt` — Project dependencies.
- `README.md` — Project documentation.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Kiry557/Accounting_system.git
cd Accounting_system
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure the Database

Make sure PostgreSQL is installed and running. Configure the database connection according to the project settings.

### 4. Run the Application

```bash
python main.py
```
